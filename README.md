Конструктор памятных карточек

## Проблема, которую решает проект
1) Утрата чувств, мнений, выводов, переживаний, вызванных прохождением определённой игры, прочтением книги, просмотром фильма, жизненным событием и многим другим. 
2) Отсутствие простого пути для того чтобы делиться с друзьями советами, мыслями, интересами, мировоззрением.
3) Подготовка ко дням рождения. Даты, важные детали и идеи подарков легко забыть или потерять среди заметок. Их можно будет записывать в карточке именинника.

## Основные сценарии пользования
Пользователь X прошёл много игр, прочитал много книг и посмотрел много фильмов. Он ведёт свой телеграм канал, куда выкладывает свои мысли, но, все его отзывы являются лишь картинкой с текстом и парой ссылок в одном и том же стиле. Когда он хочет сделать новый раздел, например, с произведениями разных видов, которые объединяет некоторый жанр, ему приходится вручную копировать в новый раздел все свои посты, которые ещё и нужно найти. А что если он в каком-то посте забыл проставить жанр? Этот пост потеряется среди сотен других. Кроме того, пользователь X пишет рецензии на специализированном для этого сайте. Однако для книг и фильмов сайты разные и неудобно переключаться между ними. А что если с сайтом что-то случится? Хотелось бы иметь копию. Что если он захочет оформить свои оценки в тирлист таблицу? До этого он вручную переносил свои оценки в тирлист таблицу на tierlistmaker, но в один день она у него слетела. В итоге пришлось снова тратить часы на восстановление по скриншотам этой таблицы, которые у него, к счастью, были. 

С конструктором памятных карточек он бы смог для своих самых любимых произведений создавать карточки, редактируя их самостоятельно или выбирая один из шаблонов и заполняя нужные поля. Например, карточка игры (вид карточки): название (обязательный минимум, остальное по желанию), логотип/картинка, сюжетная ли, если да, то дата прохождения, жанр, отзыв/рецензия, оценка по 10-балльной шкале или тирлист шкале или и то и то (атрибуты карточки). Для карточки книги возможно ещё автор, любимые персонажи, сделанные выводы и так далее. Их можно будет фильтровать (вид, жанр, оценка, наличие атрибутов, подробность описания, избранное или нет), автоматически представлять в разных видах (тирлист, альбом (как для событий из жизни, например, с фотокарточками), историческая линия). Также их можно будет группировать в колоды карт, которыми можно будет делиться в виде json файлов или просто сохранять. Изначально будет одна main колода, в которой будут лежать абсолютно все карты.

## Краткое описание основных компонент системы

Приложение будет работать на `.NET MAUI`. Информация будет храниться в JSON файлах на устройстве пользователя и получаться тоже из них.

### UI
Разные view просмотра карт, колод, профиля, тирлиста. Контролы фильтров и редактора карт.

### Application 
Методы выбора карт, колод, фильтров, вызов создания тирлиста, карты, редактирования карты, удаление.

### Domain
- Агрегаторы: профиль, шаблон карты, колода, тирлист
- Сущности: карта, атрибут, фильтр
- Типы значения: имя, автор, описание, рейтинг, уровень тирлиста
- Сервисы: создатель тирлистов

### Infrastructure
Сериализатор и десериализатор JSON.

## Описание точек расширения
Расширять можно добавляя новые виды карточек (книги, фильмы, персонажи, игры, события из жизни, музыка, аниме, да хоть шаблоны проектирования), добавляя новые виды атрибутов карточек (избранное, логотип, отзыв, любимые персонажи, игровое время, время начала, время завершения, любимый момент, выводы, вызванные эмоции, жанр и так далее), новые виды фильтров (по жанрам, видам, наличию атрибутов, подробности описания, по определённому атрибуту, по избранному, по рейтину и так далее), новые шаблоны карточек (вид + набор атрибутов для заполнения), новые виды отображения (колоды (базовый вид отображения), тирлисты, альбомы, временные линии).
- **Безопасное хранение карточек.** Копировальне нужна база данных, в которой можно безопасно сохранять созданные карточки и возвращаться к ним позже.

### Фичи в проекте  
 **Поиск и группировка карточек.** Когда карточек становится много, нужную сложно найти. Хотим добавить фильтры по темам и возможность собирать карточки в папки, например «Дни рождения», «Книги» и «Игры».
